# CareerTrack

Smart Internship & Job Application Management System.

## Overview

CareerTrack is a full-stack web application designed to help job seekers manage internship and job applications, track recruitment progress, organize interviews, and monitor their job-search performance.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Java 21
- Spring Boot
- Spring Security
- Spring Data JPA
- Maven

### Database
- PostgreSQL
